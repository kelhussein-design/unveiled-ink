# Unveiled Ink

Book development and editorial consulting by Sulay Hernandez.

Live site: https://unveiled-ink.netlify.app
Production domain (pending connection): https://unveiledink.com

## What this is

A single-page static HTML site with bilingual (English / Spanish) support via a runtime language toggle. Content is authored as JSON data files and compiled into `index.html` by `build.py`.

## File structure

```
.
├── index.html              # Built site. DO NOT edit by hand — regenerate from template + data.
├── index-template.html     # Template with placeholders that build.py fills in.
├── build.py                # Build script — run after editing any data file.
├── data/
│   ├── content.en.json     # UI chrome, hero, about, philosophy, skills, services, contact — English
│   ├── content.es.json     # Same, Spanish
│   ├── books.en.json       # Book metadata, priority order, descriptions, quotes — English
│   ├── books.es.json       # Same, Spanish
│   ├── testimonials.en.json # Author testimonials — English
│   └── testimonials.es.json # Same, Spanish
└── images/
    ├── headshot.jpg
    └── covers/*.jpg        # 43 book covers + 1 forthcoming (no cover)
```

## How the language toggle works

- Both English and Spanish content are **embedded** in `index.html` at build time under `window.DATA = { en: {...}, es: {...} }`.
- The `EN | ES` toggle in the nav calls `render(lang)`, which rebuilds the DOM from `window.DATA[lang]` — no page reload, no network request, instant swap.
- Language is persisted:
  - Via URL param: `?lang=es` loads the site in Spanish directly
  - Via localStorage key `ui_lang`
  - Priority: URL param wins, then localStorage, then default (English)
- Head meta tags (`<title>`, `og:title`, etc.) are server-rendered in English by the build. Client JS swaps them live when the language changes. This means social-media link previews and non-JS crawlers see English by default; Google executes JS and sees both.
- `<link rel="alternate" hreflang="en|es|x-default">` tags tell Google the two language versions.

## Building

```bash
python3 build.py
```

This reads the 6 JSON files in `data/` plus `index-template.html`, replaces placeholders, validates (warns on slug mismatch between EN and ES, warns on testimonial count mismatch, fails on any unreplaced placeholder), and writes `index.html`.

No dependencies beyond Python 3 standard library.

## Editing content

Edit the JSON files in `data/`, then run `python3 build.py`. Commit both the JSON and the rebuilt `index.html`.

### Things NOT to translate in `books.*.json`

- `title` — book titles stay in the language they were published in (English)
- `author` — proper nouns
- `category` — used by filter logic; must stay English (`recent`, `literary`, `popular`, `nonfiction`)
- `cover` — filename
- The `priority` list at the top — this is a list of slugs; the slugs stay stable across files

Translate only: `description`, `subtitle`, and quote `text`. Quote `source` is usually a publication name (The Washington Post, Booklist) which stays in its original language; translate biographical credits like "author of X" → "autora de X".

### Adding a new book

1. Add a cover image to `images/covers/your-book-slug.jpg`.
2. Add an entry to **both** `books.en.json` and `books.es.json` under `"books": { "your-book-slug": {...} }`. The build script will warn if slugs don't match between the two files.
3. If it should appear in the top-14 priority section, add the slug to the `priority` array — same array in both files.
4. Run `python3 build.py`.

### Adding a new testimonial

Append to the `testimonials` array in both `testimonials.en.json` and `testimonials.es.json`. Keep the two arrays the same length and in the same order.

## The Spanish translations — status

The Spanish translations in this codebase are a **draft by Claude (an AI assistant)** and need native-speaker review before going to production. Sulay is a native Spanish speaker and will proofread.

A side-by-side review document is included: `SPANISH_REVIEW.docx`. Edits should be made to the JSON files, then `python3 build.py`.

**Style choices that may warrant discussion:**

- Uses `tú` throughout (not `usted`) — matches the warm, first-person voice of the English original
- Neutral Latin American Spanish (no strong regionalisms)
- Book titles and publication sources remain in English
- 16 subtitle patterns translated (e.g., "A Novel" → "Una novela", "A Memoir" → "Unas memorias") — see `SPANISH_REVIEW.docx` for the full list

## Deployment

The site is on Netlify, deployed from the `main` branch of github.com/kelhussein-design/unveiled-ink. Netlify Forms handles the contact form (configured via `data-netlify="true"` and `netlify-honeypot="bot-field"` attributes on the form, which are generated by `render()`).
